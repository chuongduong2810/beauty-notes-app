Project Brief — Spatial Sticky Notes App

We want to build a modern sticky notes application focused on immersive interaction, fluid animation, and spatial design rather than traditional productivity layouts.

The app should feel calm, tactile, and creative — like a digital thinking space. Users can create, drag, resize, and organize sticky notes inside an infinite canvas environment with smooth motion and subtle 3D depth.

Key visual direction:

* Minimal but atmospheric UI
* Soft lighting, glassmorphism, gradients
* Smooth physics-based interactions
* Spatial/parallax effects using Three.js
* Highly polished animations and transitions

Core features:

* Infinite canvas
* Draggable sticky notes
* Zoom and pan interactions
* Persistent autosave
* Smooth camera movement
* Responsive design for desktop/tablet

Preferred technologies:

* React + Vite
* Three.js / React Three Fiber
* Framer Motion or React Spring
* Zustand for state management
* Supabase for backend/storage

The priority is not feature quantity, but user experience quality. The product should feel elegant, satisfying, and emotionally engaging while remaining lightweight and usable.

Inspiration references:

* Linear
* Milanote
* Cosmos
* Apple-style motion design
